# Application profiles

Reserved for future application profiles so the appliance can demonstrate suites
other than Mijn Bureau. **Structure only — no profiles are built in v0.1.**

A profile plugs into the same manifest + Helmfile-driver pattern as
`apps/mijn-bureau/` without changing the host or the bootstrap. Adding one is
explicitly out of v0.1 scope (see `docs/adr/0001-project-scope.md`).
