# Application profiles (structure only, nothing built in v0.1)

Reserved for future application profiles so the appliance can demonstrate
suites other than Mijn Bureau. A profile plugs into the same manifest +
Helmfile-driver pattern as `apps/mijn-bureau/` without changing the host or the
bootstrap. Adding one is out of v0.1 scope (`docs/adr/0001-project-scope.md`).
