# Code of conduct / Gedragscode

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) ([Nederlandse vertaling](https://www.contributor-covenant.org/nl/version/2/1/code_of_conduct/)).

In short: be respectful and constructive, assume good intent, and keep discussions about the work. Harassment, discrimination and personal attacks are not accepted.

**Reporting:** report unacceptable behaviour to the maintainer privately (GitHub: the repository owner). Reports are handled confidentially. The maintainer decides on measures, as described in the Contributor Covenant's enforcement guidelines.

*Kort in het Nederlands:* we gaan respectvol en opbouwend met elkaar om. Ongewenst gedrag meld je vertrouwelijk bij de beheerder.
