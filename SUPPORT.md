# Ondersteuning

Wat je van het onderhoud van de DAWO appliance mag verwachten, en waar je terechtkunt. Volgens de [OWC-afspraak](https://github.com/OpenWebconcept/.github) hoort daar minimaal een jaar onderhoud bij, met het einde een jaar vooraf aangekondigd.

> **Concept ([#186](https://github.com/EduardWitteveen/dawo-appliance/issues/186)).** De appliance is nu een **experimentele demonstrator zonder onderhoudsgarantie**. Een onderhoudstermijn volgt bij de overdracht naar een beherende organisatie.

## Onderhoudstermijn

- **Beheerder:** de maintainer (zie `maintenance` in [publiccode.yml](./publiccode.yml)).
- **Onderhoudsgarantie:** geen, zolang de appliance experimenteel is (`developmentStatus: development`). Fouten worden opgepakt zoals de tijd het toelaat.
- **Bij een onderhoudstermijn** (na de overdracht): minimaal één jaar per release, en het einde minimaal een jaar vooraf aangekondigd in de README, een issue, de CHANGELOG en `publiccode.yml`.

## Wat je mag verwachten

| Wat | Hoe |
| --- | --- |
| **Fouten** | Meld een issue. De beheerder reageert en plant een oplossing voor een volgende versie. |
| **Beveiligingslekken** | Niet via een openbaar issue, maar via [SECURITY.md](./SECURITY.md). |
| **Ondersteunde versies** | Alleen de laatste release. |
| **Wensen en bijdragen** | Via een issue en een pull request ([CONTRIBUTING.md](./CONTRIBUTING.md)), ook van andere partijen en concurrenten. |
| **Nieuwe versies** | Een GitHub-release per versie, met de wijzigingen in de [CHANGELOG](./CHANGELOG.md). Volg de releases via *Watch > Custom > Releases*. |
| **Gebruik** | [README](./README.md), [de USB-schijf maken](./docs/live-usb.md), [demoscript](./docs/demo-script.md). |

**Niet inbegrepen:** ondersteuning bij gebruik met echte gegevens (de appliance is daar niet voor bedoeld), het beheer van jouw laptop of netwerk, en maatwerk.

## Kanalen

- **Issues:** [github.com/EduardWitteveen/dawo-appliance/issues](https://github.com/EduardWitteveen/dawo-appliance/issues), voor fouten, vragen en wensen.
- **Beveiliging:** [SECURITY.md](./SECURITY.md).

## English summary

Today the DAWO appliance is an **experimental demonstrator without a maintenance guarantee** (draft, #186). Bugs and wishes go to GitHub issues, security reports privately via SECURITY.md. After a handover to a maintaining organisation, OWC terms apply: at least one year of maintenance per release, the end announced a year ahead.
